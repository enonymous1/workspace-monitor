Not connected

No Classroom token is configured, so no courses are shown here (and none are invented).

  1. In Google Cloud Console, create an OAuth client for the business's Google account and enable the Classroom API.
  2. Authorize with read-only scopes only: classroom.courses.readonly, classroom.coursework.students.readonly, classroom.rosters.readonly.
  3. Set the resulting short-lived access token as WORKSPACE_MONITOR_CLASSROOM_TOKEN when starting the app. Do not commit it, and do not put it in the database.
  4. Reload this page. If the token is rejected or expired, the error will be shown here instead of fake data.

This page is most useful for staff training / onboarding courses. For a general business with no training classes, it will simply show an empty course list once connected.
